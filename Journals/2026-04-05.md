### **HOST CONFIGUARTION**

**1. Configure the Host OS**

1. **Update OS packages**

```
sudo pacman -Syu
```

2. **Enable virtualization**

* Check CPU virtualization support:
```
egrep -c '(vmx|svm)' /proc/cpuinfo
```
> If lines > 0, the CPU supports VT-x/AMD-V.

* Enable virtualization in BIOS.

3. **Install necessary packages**

```
sudo pacman -S qemu libvirt virt-manager iproute2 ebtables dnsmasq
```

* `qemu` & `libvirt` -> VM management
* `virt-manager` -> GUI for managing VMs
* `iproute2` -> network bridging
* `ebtables/dnsmasq` -> DHCP and bridging support

---

**2. Configure Virtualization (KVM/QEMU)**

1. **Enable libvirtd service**

```
sudo systemctl enable libvirtd --now
```

2. **Create Bridges on Host**

> Bridges
> 1. Attacker VM -> Firewall VM in
> 2. Firewall VM out -> NIC-1
> 3. NIC-2 -> Endpoint VM
> 4. NIC-3 -> IDS VM

```
# 1. Attacker VM -> Firewall (IN)
sudo ip link add br0 type bridge
sudo ip link set br0 up

# 2. Firewall (OUT) -> NIC-1
sudo ip link add br1 type bridge
sudo ip link set br1 up

# 3. NIC-2 -> Endpoint VM
sudo ip link add br2 type bridge
sudo ip link set br2 up

# 4. NIC-3 -> IDS VM
sudo ip link add br3 type bridge
sudo ip link set br3 up
```

```
sudo ip link set enp1s0 master br1
sudo ip link set enp2s0 master br2
sudo ip link set enp3s0 master br3
```

```
sudo ip link set br3 promisc on
sudo ip link set enp3s0 promisc on
```

3. **Create VM Configurations**

**Attacker VM (Arch Linux)**

```
virt-install \
--name attacker \
--ram 4096 \
--vcpus 2 \
--disk path=/var/lib/libvirt/images/attacker.qcow2,size=40 \
--os-variant archlinux \
--network bridge=br0,model=virtio \
--graphics none \
--console pty,target_type=serial \
--import
```

**Firewall VM (IPFire)**

```
virt-install \
--name firewall \
--ram 2048 \
--vcpus 2 \
--disk path=/var/lib/libvirt/images/firewall.qcow2,size=20 \
--os-variant generic \
--network bridge=br0,model=virtio,mac=00:16:3e:aa:aa:01 \
--network bridge=br1,model=virtio,mac=00:16:3e:aa:aa:02 \
--graphics none \
--console pty,target_type=serial \
--import
```

**Endpoint VM (Metasploitable2)**

```
virt-install \
--name endpoint \
--ram 1024 \
--vcpus 1 \
--disk path=/var/lib/libvirt/images/endpoint.qcow2,size=10 \
--os-variant linux2.6 \
--network bridge=br2,model=virtio \
--graphics none \
--console pty,target_type=serial \
--import
```

**IDS VM (Suricata)**

```
virt-install \
--name ids \
--ram 2048 \
--vcpus 2 \
--disk path=/var/lib/libvirt/images/ids.qcow2,size=20 \
--os-variant generic \
--network bridge=br3,model=virtio \
--graphics none \
--console pty,target_type=serial \
--import
```

4. **Verify Bridges and VM Connectivity**

```
bridge link
bridge addr
virsh list --all
virsh console attacker
ping x.x.x.x
```

### **FIREWALL CONFIGUARTION**

**1. Interface Assignment (CRITICAL)**

IPFire uses color-coded zones:

| Zone  | Interface | Purpose  |
| ----- | --------- | ---------|
| GREEN | `eth0`    | Internal |
| RED   | `eth1`    | External |

---

**2. Enable Routing + NAT**

IPFire does NAT by default between GREEN -> RED.

NAT (Masquerading)

```
Firewall -> NAT -> Masquerading
```

Ensure:

* GREEN -> RED is enabled

**3. Basic Firewall Policy**

Default IPFire behavior:

* GREEN -> ANY = ALLOWED
* RED -> GREEN = BLOCKED

**4. Create Controlled Attack Rules**

### Allow Attacker -> Endpoint

```
Firewall -> Firewall Rules -> New Rule
```

Add:

* **Source:** 10.0.0.0/24
* **Destination:** 192.168.1.0/24
* **Service:** ANY
* **Action:** ACCEPT
* **Log:** ENABLED

**5. Enable Logging**

```
Firewall -> Firewall Options
```

Enable:
* Log dropped packets
* Log accepted connections
* Log new connections

**6. Disable Unnecessary Services**

```
System -> Services
```

Disable:
* Proxy (unless testing)
* DHCP (if not needed)
* VPN (unless testing scenarios)

**7. Time Sync**

```
System -> Time
```

* Enable NTP
* Use same time source as:
  * IDS VM
  * Attacker VM
  * Splunk

### **IDS CONFIGUARTION**

**1. IDS Interface Setup**

IDS interface must be **passive (no IP)**.

```
sudo ip addr flush dev eth0
sudo ip link set eth0 up
sudo ip link set eth0 promisc on
```

Verify:

```
ip a show eth0
```

**2. Install Suricata**

```
sudo pacman -Syu
sudo pacman -S suricata jq
```

**3. Configure Suricata**

```
sudo nano /etc/suricata/suricata.yaml
```

Set interface:

```
af-packet:
  - interface: eth0
    cluster-id: 99
    cluster-type: cluster_flow
    defrag: yes
```

Enable promiscuous mode:

```
af-packet:
  - interface: eth0
    promisc: yes
```

lab networks:

```
vars:
  address-groups:
    HOME_NET: "[10.0.0.0/24,192.168.1.0/24]"
```
Enable EVE JSON logging:

```
outputs:
  - eve-log:
      enabled: yes
      filetype: regular
      filename: /var/log/suricata/eve.json
      types:
        - alert
        - http
        - dns
        - tls
        - flow
```

**4. Download Rules**

```
sudo suricata-update
```

**5. Start Suricata (IDS Mode)**

```
sudo systemctl enable suricata
sudo systemctl start suricata
```

Or manual run:

```
sudo suricata -c /etc/suricata/suricata.yaml -i eth0
```

**6. Verify Traffic Capture**

```
sudo tcpdump -i eth0
```

**7. Generate Test Alerts**

From attacker VM:

```
nmap -sS 192.168.1.100
```

Check alerts:

```
cat /var/log/suricata/fast.log
```

Or:

```
jq . /var/log/suricata/eve.json
```

**8. Performance Tuning**

```
sudo nano /etc/suricata/suricata.yaml
```

Increase buffers:

```
af-packet:
  - interface: eth0
    ring-size: 200000
    block-size: 1048576
```

**9. Disable Offloading**

Prevents packet loss:

```
sudo ethtool -K eth0 gro off
sudo ethtool -K eth0 lro off
sudo ethtool -K eth0 tso off
```

### **ENDPOINT CONFIGUARTION**

Assign a static IP

```
sudo nano /etc/network/interfaces
```

```
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
```

Restart networking:

```
sudo /etc/init.d/networking restart
```

Verify:

```
ip a
ping 192.168.1.1
```
