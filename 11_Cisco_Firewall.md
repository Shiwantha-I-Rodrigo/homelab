# CISCO FIREWALLS

## SUMMARY

Cisco offers different firewall technologies.

| **Type**                                            | **Description / Use Case**                                                                                           |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Cisco ASA (Adaptive Security Appliance)**         | Hardware firewall for perimeter security; supports VPNs, NAT, intrusion prevention, and deep packet inspection.      |
| **Cisco Firepower NGFW (Next-Generation Firewall)** | Advanced firewall with application awareness, intrusion prevention (IPS), URL filtering, malware protection.         |
| **Cisco IOS Firewall**                              | Software firewall feature built into Cisco routers; provides basic traffic filtering with ACLs, inspection, and NAT. |
| **Cisco Meraki MX**                                 | Cloud-managed firewall appliance with easy management, VPN, and threat protection for SMB and enterprise.            |

**Key Functions of a Cisco Firewall**

- Packet Filtering: Blocks or allows traffic based on IP addresses, ports, and protocols.
- Stateful Inspection: Tracks active sessions and allows return traffic only for legitimate sessions.
- NAT (Network Address Translation): Hides internal IP addresses from external networks.
- VPN Support: Secures remote access or site-to-site connections.
- Intrusion Prevention & Detection: Monitors traffic for attacks or malicious behavior (especially in NGFW).
- Application Awareness: Can identify and control traffic by application type, not just port number.
